## Зависимости

- Python 3.10+
- `requests`
- `beautifulsoup4`

Установка (виртуальное окружение):

```bash
python3 -m venv .venv 

.venv\Scripts\activate. #Windows
source .venv/bin/activate #MacOS

pip install -r requirements.txt
```

## Запуск

```bash
python avito_parser.py
```

По умолчанию используется встроенный список артикулов из задания,
результат пишется в `result.csv`. Можно передать свой список и путь:

```bash
python avito_parser.py --articles articles.csv --out result.csv
```

Формат `articles.csv`: одна строка на артикул. Поиск всегда выполняется по артикулу.

## Как задаются фильтры
- **Регион (Москва и Московская область)** — задаётся сегментом URL
  `moskva_i_mo` в `AVITO_BASE_URL`, дополнительно на этапе фильтрации
  каждое объявление проверяется по тексту адреса (`REGION_KEYWORDS`):
  объявления не из Москвы/МО отбрасываются, даже если сайт вернул их
  в выдаче.
- **Состояние — только новое** — передаётся параметром запроса
  `state=new`, дополнительно каждое объявление проверяется по тексту
  состояния (`NEW_CONDITION_KEYWORDS`) и отбрасывается, если оно не
  "новое".
- **Сортировка по возрастанию цены** — передаётся параметром `s=104`
  на сервер, но скрипт в любом случае досортировывает результат по
  цене самостоятельно (`filter_and_rank`), чтобы не зависеть от того,
  правильно ли сервер применил сортировку.

## Что происходит, если Avito блокирует прямой запрос

Задание не требует обхода капчи/блокировок Avito. Если прямой запрос не
удался (сетевая ошибка, код ответа не 200, признаки капчи), скрипт:

1. ищет заранее сохранённую HTML-страницу `fixtures/<артикул>.html`
   и разбирает её вместо живого ответа;
2. если такого файла нет — пишет по этому артикулу одну строку
   со статусом «ошибка».

В комплекте два синтетических тестовых файла (`fixtures/223112R020.html`,
`fixtures/233002F700.html`) с объявлениями, придуманными для демонстрации
фильтрации по региону и состоянию, обработки дублей и объявлений без цены.
Если Avito с данного IPдоступен, скрипт в первую очередь делает живой запрос и использует fixtures
только как запасной вариант.

## Формат result.csv

Одна строка — одно отобранное объявление (плюс отдельные строки со
статусом «не найдено» / «ошибка» для артикулов без результата):

| Колонка | Описание |
|---|---|
| артикул | искомый артикул |
| поисковый_запрос | текст, отправленный в поиск Avito |
| заголовок | заголовок объявления |
| цена | цена, число (без валюты и пробелов) |
| город_или_регион | город/регион из объявления |
| состояние | состояние товара |
| ссылка | ссылка на объявление |
| место_по_цене | место в отсортированной по цене пятёрке (1–5) |
| статус | `ок (live/fixture)`, `не найдено` или `ошибка` |
| дата_время_проверки | когда объявление было проверено |

## Обработка ошибок и дублей

- Объявления без числовой цены не участвуют в отборе топ-5.
- Объявления не в состоянии «новое» или не из Москвы/МО отфильтровываются.
- Повторяющиеся объявления (одинаковая ссылка) внутри одного артикула формируються в одно — остаётся минимальная цена.
- Если по артикулу ничего не найдено — строка со статусом «не найдено».
- Если страницу не удалось получить ни живьём, ни из fixtures — строка
  со статусом «ошибка».
